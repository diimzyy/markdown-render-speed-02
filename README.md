# markdown-render-speed-02

A faster drop-in replacement for marked 18.1.3's markdown parser.

## What it does

This entry provides a CommonMark/GFM-compatible markdown parser that renders identical HTML to marked 18.1.3 with default options, but with significantly improved performance.

## Run locally

```bash
node main.ts
```
